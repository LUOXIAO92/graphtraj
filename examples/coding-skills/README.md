# Customized coding Skill samples

These nine samples preserve the methods used to develop GraphTraj. They are
coding-specific reference material, separate from GraphTraj's general methods
in `skills/` and from its Python runtime package. They are not installed,
registered or discovered automatically by GraphTraj. Copy or adapt selected
methods using your Runtime's supported Skill configuration only when wanted.

The samples were copied from this project's customized Harness Skills on
2026-09-28. They preserve the existing implementation, test ownership, review,
recovery and evidence instructions. They are not restorations of upstream
versions. Some methods derive from the project's previously adopted Matt Pocock
and ponytail materials; the retained files are the provenance of this snapshot,
not a claim of correspondence to a particular upstream revision. Existing
license and invocation metadata are retained where supplied.

Included: `implement`, `tdd`, `code-review`, `ponytail`, `ponytail-review`,
`to-spec`, `to-tickets`, `prototype`, and `resolving-merge-conflicts`. The UI/logic
choice inside `prototype` is a software-method choice; there is no general/coding
domain router to maintain. General Harness Skills are not copied here.

Project-specific instructions are examples, not GraphTraj requirements. Adapt
named coordination and testing responsibilities to your project. Existing links
to the general task-delivery Skill now point to `skills/task-delivery`; the
coding-ticket budget reference is retained beside `to-tickets`. That reference
points to the general recovery instructions. Other files retain their content.
When installing a sample separately, make its explicitly referenced methods
available through your Runtime; copying a file does not configure them.
