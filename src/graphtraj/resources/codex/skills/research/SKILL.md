# Research

State the question the research must resolve and the evidence needed to answer
it. Use the task's existing scope and available material to focus the search.

Delegate a bounded research assignment when background work is authorized and
lets the caller continue useful work. Otherwise investigate directly. Give the
researcher the question and source constraints, without prescribing the answer.

Follow material claims to their primary sources. Record what a source actually
establishes, its date or version where relevant, and limitations that affect
the conclusion. Separate source findings from your own inferences; reconcile
conflicting evidence or leave the uncertainty explicit.

For software documentation, API or implementation research, read
[software sources](references/coding.md).

Capture findings in one Markdown note at the project's established research
location. Cite the source beside each material claim, link relevant artifacts,
and answer the original question. In a Harness Project, delegated researchers
return findings to Main for Project Document updates or use the report location
explicitly supplied by Main.
