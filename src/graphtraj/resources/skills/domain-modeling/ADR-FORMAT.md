# Decision record format

Follow the project's decision-record convention. The default is a numbered
Markdown file in `docs/adr/`; inspect existing numbers before choosing the next.
Create the directory only when there is an actual decision to record.

A short title and a paragraph stating the context, decision and reason usually
suffice. Include alternatives, consequences or status when they explain a
real trade-off or a later change in the decision.

Record only decisions that are costly to reverse, surprising without context,
and chosen among genuine alternatives. A boundary on what evidence can support
a conclusion or a commitment to a particular source can qualify; ordinary
reversible working choices usually do not.
