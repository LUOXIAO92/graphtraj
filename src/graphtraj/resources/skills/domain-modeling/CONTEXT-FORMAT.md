# Context format

Use a title naming the context, a short description, and a Language section.
Each entry names a concept, defines it in one or two sentences, and lists
ambiguous synonyms to avoid where that distinction matters.

Record terms whose precise meaning matters to this project. Ordinary vocabulary
needs no glossary entry. Keep operational details in the documents that own
them. Group terms only when the groups clarify their relationships.

Use one root `CONTEXT.md` unless a context map already locates separate
vocabularies. A map lists the contexts, links their documents and explains the
relationships between them. Follow those links for the current topic; ask
about its context only if the existing material leaves that unresolved.
