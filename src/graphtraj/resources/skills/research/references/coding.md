# Software sources

Use official documentation, published specifications, first-party API material
and the relevant source repository. Check the version used by the project.
For a behavior claim, follow the current implementation and its public callers;
a tutorial or an unrelated release may describe different behavior.

When a fact can be established from the local code or installed package, cite
that evidence. For changeable external behavior, verify the maintained primary
source and distinguish documented behavior from an inference about support.
